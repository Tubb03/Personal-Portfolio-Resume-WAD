About Me

I am a passionate Full Stack Developer with 5 years of experience specializing in JavaScript ecosystems. My core philosophy is rooted in building efficient, maintainable, and highly responsive user interfaces. While I specialize in modern tools, my foundation is built on mastering the fundamentals of HTML5, CSS3, and Vanilla JavaScript—the true building blocks of the web.

I thrive on solving complex problems and turning creative ideas into functional realities. Beyond the code, I am committed to accessibility, ensuring all my projects meet WCAG guidelines.

Featured Projects

Collaborative Canvas

A real-time drawing application built to showcase complex DOM manipulation and event handling without external libraries.

This project features custom-implemented drag-and-drop functionality, undo/redo state management, and basic user authentication logic simulation. It was a key learning experience in minimizing DOM reflows and optimizing performance in a highly interactive setting.

Tags: JavaScript, HTML5 Canvas, Data Persistence Simulation

Fluid Mart

A fully responsive e-commerce product page mockup designed purely with advanced CSS Grid and Flexbox techniques.

The layout is optimized for four major breakpoints (mobile, tablet, small desktop, large desktop). Key CSS features include custom properties (variables), calc() functions, and media queries for image resolution switching. The goal was 100% responsiveness without any framework.

Tags: CSS3, Responsiveness, Accessibility, Semantic HTML

Developer Quiz Master

An interactive quiz app that loads questions from a local JSON object and tracks user scores dynamically.

This application focuses on state management in Vanilla JS. It utilizes a simple state object to manage the current question index, score, and timer. Error handling is included to ensure the quiz gracefully handles invalid answer submissions.

Tags: JavaScript, DOM Manipulation, Local Storage, JSON
